# Midnight Train Simulator

A deliberately boring web game built with HTML, CSS, and JavaScript that simulates the feeling of waiting for a train at midnight. How long can you stay awake before your train arrives?

*Dedicated to everyone who commutes. Created for a university assignment.*

## How to Play
- Click the eye icons that pop up on the screen to stay awake.
- Try not to fall asleep (either in-game or in real life).

## Web APIs & Technologies
- **DOM (Document Object Model) API:** Drives the interactive user interface, randomizes button placement, and manages game state transitions.
- **Web Audio API:** Implements immersive, randomized ambient audio.
- **Web Animations API:** Handles smooth, controllable eyelid movement animations.
